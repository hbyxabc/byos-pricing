钱怎么走

  1. 用「官方标价货值」计量额度：如果这些 token 按官方 API 标价卖，大约值多少美元。这是记账单位，不是买家实际付款价，也不是中转站零售价。
  2. 买家按相对官方打几折付钱。成交货值 × 售价打折倍率 = 成交额（买家真正掏的钱）。
  3. 成交额里平台抽走约定比例，剩下按卖家人数均分，得到单卖家月净收入。
  4. 市场成交量取「卖家可售」与「买家愿买」的较小值——谁更少，谁就卡脖子。

怎么算的
  1. 单卖家可售货值 = 官方标价月货值 × 打满程度 × 愿意外售的比例。
  2. 供给总量 = 卖家人数 × 单卖家可售货值。
  3. 单买家需求货值 = 取较小值（愿用货值上限， 愿付预算 ÷ 相对官方售价倍率）。预算不够就买少一点；愿用封顶就不再多买。
  4. 需求总量 = 买家人数 × 单买家需求货值。
  5. 成交货值 = 取较小值（供给总量， 需求总量）。
  6. 成交额 = 成交货值 × 相对官方售价倍率（买家真正付出去的总钱）。
  7. 平台收入 = 成交额 × 抽成比例；卖家总净 = 成交额 ×（1 − 抽成）；再除以卖家人数得单卖家净收入。
  8. 满负荷单卖家净 = 可售货值 × 售价倍率 ×（1 − 抽成），假设需求永远够吃。
  9. 供给利用率 = 成交货值 ÷ 供给总量；需求满足率 = 成交货值 ÷ 需求总量。
  10. 谁卡脖子：供给更少 → 供给不足（缺货）；需求更少 → 需求不足（卖家吃不饱）；差不多 → 大致均衡。

单位统一是美元。货值一律按「官方标价」记账；成交额、平台收入、卖家净收入才是真金白银。
